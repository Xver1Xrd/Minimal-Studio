# Minimal Studio · 1.1.0

**Minimal × Studio** — локальное Android-приложение для визуальных коллекций желаний и идей.

- **Никаких аккаунтов, аналитики, рекламы и серверов.** Манифест не запрашивает разрешения `INTERNET`.
- После установки карточки, вложения, черновики и поиск работают без сети. Открытие ссылки на магазин/игру передаётся внешнему браузеру, которому может понадобиться интернет.
- Android 8.0+ (`minSdk 26`); Kotlin, Jetpack Compose, Room, Coil.
- **Важно:** это **исходный проект для сборки**, а не уже собранный/протестированный APK. В среде подготовки не было Android SDK и доступа к Maven/Gradle, поэтому фактическая Android-компиляция и тестирование на устройстве не проведены. Сборку, UI-тестирование и проверку подписанного APK необходимо выполнить перед распространением. Не выдавайте эту версию за проверенный production release до прохождения `docs/RELEASE_CHECKLIST.md`.

## Основные возможности

| Раздел | Возможности |
| --- | --- |
| Хотелки | Любые желания (не только товары), описание, изображения, произвольные файлы, цена, ссылка, приоритет, статус, заметки |
| Идеи | Картинки, документы, ссылки, категории, заметки, простые списки шагов с отметками выполнения |
| Общее | Плавающий переключатель «Хотелки / Идеи», список или плитка, поиск, теги, коллекции, связи между карточками |
| Действия | Долгое нажатие, контекстное меню, массовый выбор, избранное, архив, копирование, обмен текстом, редактирование |
| Безопасность данных | Корзина с восстановлением/окончательным удалением, локальные текстовые черновики, переносимый ZIP-бэкап с фотографиями и файлами |

**Что НЕ входит:** облако, регистрация, ИИ, автосбор информации с сайтов, мониторинг цен, совместная работа, Push-уведомления, виджеты, полноформатный блочный редактор, PIN-код и шифрование данных. Уровень возможностей нужно понимать до установки: фотографии и текст сохраняются локально без отдельного шифрования приложением.

## Установка и сборка в Linux Fedora / Manjaro

1. Установите **Android Studio** и Android SDK Platform **36** с Build Tools **35.0.0**. Нужен JDK **17** (также можно использовать встроенный в Android Studio JDK соответствующей версии).
2. Откройте папку `minimal-studio` в Android Studio или терминале.
3. Если `gradlew` ещё не является официальным Gradle Wrapper, в проекте есть Linux-скрипт первичной загрузки Gradle. Для **первой сборки нужен интернет**, чтобы загрузить Gradle и зависимости. После загрузки кэшей процесс может работать офлайн.

```bash
chmod +x gradlew
./gradlew wrapper --gradle-version 8.13
./gradlew lintDebug testDebugUnitTest assembleDebug
```

4. APK отладки появится в `app/build/outputs/apk/debug/app-debug.apk`. Установка на устройство с включённой USB-отладкой:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Или нажмите **Run** в Android Studio. Если среда разработки обнаружила несовместимые версии SDK/Gradle, **не обновляйте их вслепую** — сначала проверьте совместимость версий в Gradle-файлах.

### Сборка подписанного release APK

Задайте собственную подпись: создание ключа (выполняется один раз; создайте надёжный пароль и резервную копию ключа):

```bash
keytool -genkeypair -v -keystore "$HOME/minimal-studio-release.jks" \
  -alias minimalstudio -keyalg RSA -keysize 3072 -validity 10000
```

Затем:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
./scripts/build-release.sh "$HOME/minimal-studio-release.jks" minimalstudio
```

Скрипт запускает `lintRelease`, `testDebugUnitTest`, `assembleRelease`, `zipalign`, `apksigner`, `apksigner verify`. Файл после удачной сборки: `dist/minimal-studio-1.1.0.apk`. **Никогда не выкладывайте `.jks` и пароли в Git**: без сохранённого ключа нельзя будет выпускать совместимые обновления обычным способом.

Файл `.github/workflows/android.yml` предоставляет автоматическую проверку сборки и публикацию debug/unsigned-release APK как GitHub Actions artifacts, если скопировать этот проект в Git-репозиторий с включённым Actions.

## Перенос и восстановление данных

1. Откройте настройки → **Создать резервную копию**. Выберите папку на устройстве/внешнем накопителе.
2. ZIP содержит `data.json` и приватные вложения (`files/UUID`). Архив хранит **все карточки, включая корзину**.
3. На втором телефоне установите приложение, зайдите в настройки → **Восстановить из архива** и выберите ZIP. **Текущая библиотека будет заменена**. Перед восстановлением сделайте резервную копию текущих данных.
4. Импорт проверяет версию, дубликаты идентификаторов, пути и размеры, копирует файлы в новую область и только после подготовки заменяет таблицы внутри транзакции Room. ZIP ограничен 1 ГБ общего несжатого содержимого вложений, 200 МБ на вложение, до 3000 вложений и 20 000 карточек.

**Корзина:** удаление на экранах карточек перемещает их в корзину без потери фотографий. В настройках → Корзина можно восстановить любую карточку или окончательно удалить её. Пустая корзина не занимает место. **Автоматической очистки по времени нет**.

**Черновики:** приложение локально сохраняет поля редактора с небольшой задержкой и восстанавливает их при повторном открытии того же редактора. Выбранные, но ещё не сохранённые файлы/URI не входят в черновики, их нужно прикрепить повторно. После подтверждённого успешного сохранения текстовый черновик удаляется. Несохранённые черновики не включены в ZIP-бэкап.

**Приватность:** приложение не запрашивает сеть, но *не шифрует* содержимое базы/вложений и ZIP. Храните экспортированные ZIP в безопасном месте и используйте блокировку экрана. При удалении приложения Android может удалить и его внутреннее хранилище; ручные ZIP-копии — основной способ восстановления.

## Для разработчиков

- `app/src/main/java/com/minimalstudio/app/ui/` — UI Jetpack Compose и навигация.
- `app/src/main/java/com/minimalstudio/app/data/` — модели, Room 2, репозиторий, файлы, черновики.
- `app/src/test/` — JUnit-проверки внешних ссылок.
- `app/src/androidTest/` — проверка базы/корзины на Android-устройстве или эмуляторе.
- `docs/RELEASE_CHECKLIST.md` — обязательный набор тест-кейсов перед публикацией.
- `scripts/verify-source.py` — не требующая SDK структурная проверка (НЕ Android-сборка).

Команды:

```bash
python3 scripts/verify-source.py
./gradlew lintDebug testDebugUnitTest assembleDebug
./gradlew connectedDebugAndroidTest  # нужен подключенный эмулятор или телефон
```

База имеет миграцию `1 -> 2`: добавлено `cards.deletedAt`, данные из версии 1.0 сохраняются при обновлении. Избегайте `fallbackToDestructiveMigration()`.
