# Minimal Studio — сведения о приватности (локальное приложение)

Версия 1.1.0. Приложение не содержит учётных записей, облака, рекламных SDK, SDK аналитики или сетевых API. Разрешение Android `INTERNET` не объявлено.

Данные, которые пользователь добавляет добровольно: названия и описания, изображения, файлы, цены, ссылки, категории, теги и другие заметки. Они хранятся во внутренней области приложения на устройстве пользователя. Локальные черновики сохраняются в приватных настройках приложения.

Если пользователь выбирает «Поделиться», из приложения в выбранное Android-приложение передаются текстовые сведения карточки. Если пользователь нажимает на сохранённую ссылку, она открывается во внешнем приложении (например, браузере), и дальнейшая обработка этой ссылки зависит от него.

Экспорт ZIP создаётся исключительно по явному действию пользователя и сохраняется в выбранное пользователем место. **ZIP не зашифрован**. Удаление приложения может удалить внутренние данные. Для сохранения информации рекомендуется регулярно создавать резервные копии.

Внутренние данные не имеют дополнительного пользовательского шифрования в этой версии; безопасность зависит в том числе от защиты Android-устройства. Это описание относится только к исходному приложению без сторонних модификаций.
