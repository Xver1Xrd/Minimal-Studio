# Minimal Studio 1.1.0 — релизный чек-лист

Это список проверок **для выполнения на реальном Android / эмуляторе**, не утверждение о пройденных тестах.

## Сборка
- [ ] Gradle Sync проходит в чистой Android Studio.
- [ ] `lintDebug`, `lintRelease`, `testDebugUnitTest` проходят без ошибок.
- [ ] `assembleDebug` и `assembleRelease` создают APK.
- [ ] `connectedDebugAndroidTest` проходит на Android 8.0 (API 26) и на современной версии Android.
- [ ] Подписанный APK проходит `apksigner verify` и устанавливается на устройство.
- [ ] APK запускается без сети и без каких-либо разрешений доступа ко всей галерее.

## Карточки
- [ ] Создание хотелки только с названием, без ссылок и изображений.
- [ ] Создание идеи с текстом, файлами, фотографиями и чек-листом.
- [ ] Отображение пустого списка, поиск по нескольким полям, сортировка, фильтр по коллекциям.
- [ ] Переключение верхнего острова, экран информации, редактирование и сохранение.
- [ ] Долгое нажатие и массовое выделение, копирование, архив, избранное.
- [ ] Связь между хотелкой и идеей, открытие связанной карточки.
- [ ] Передача ссылки и изображения из Android Share в приложение.
- [ ] Открытие локального PDF/изображения через FileProvider без разрешений READ_STORAGE.
- [ ] Портретная и альбомная ориентация, системный размер шрифта 200%, Android TalkBack.

## Надёжность
- [ ] Выбор вложения 0 байт, 200 МБ, чуть больше 200 МБ.
- [ ] Отмена выбора файла, отмена редактирования и повторный вход (черновик).
- [ ] Ошибка записи на заполненном диске: текст остаётся доступен для повторной попытки.
- [ ] Двойное быстрое нажатие «Сохранить» не создаёт дубликат.
- [ ] Сохранение с удалением старого фото, затем повторное открытие карточки.
- [ ] Удаление в корзину, восстановление, окончательное удаление, очистка всей корзины.
- [ ] Старые карточки версии 1.0 остаются после обновления до 1.1.0 (Room migration).
- [ ] Приложение переживает принудительную остановку и перезагрузку телефона.

## Резервное копирование
- [ ] Экспорт пустой библиотеки и экспорт библиотеки с несколькими вложениями.
- [ ] Восстановление ZIP с предыдущей версии 1.0 (обратная совместимость).
- [ ] Восстановление ZIP 1.1.0 на другом устройстве: тексты, изображения, файлы, корзина.
- [ ] Отмена выбора ZIP сохраняет текущую библиотеку.
- [ ] Повреждённый ZIP не повреждает текущую библиотеку.
- [ ] ZIP с лишним файлом, дубликатом UUID, некорректным JSON, zip-bomb отвергается.
- [ ] Во время восстановления недостаточно свободной памяти: старая библиотека остаётся доступна.
- [ ] После восстановления нет потерянных ссылок на обложки / файлы.

## Финальные решения перед публичным релизом
- [ ] Финализировать название, пакет приложения (`applicationId`) до первой публикации.
- [ ] Подготовить оригинальную иконку, скриншоты и политику конфиденциальности.
- [ ] Проверить подпись и надёжно сохранить keystore.
- [ ] Протестировать многозадачность, медленные/старые телефоны, большой объём данных.
- [ ] Проверить актуальные требования Google Play (targetSdk, публикация, политика данных), если планируется Play Store.
