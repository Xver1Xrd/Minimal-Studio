# Дорожная карта Minimal Studio

## Версия 1.1.0 — реализовано в исходном коде (Android-сборка ожидает проверки)

- [x] Нативный тёмный интерфейс, плавающий переключатель «Хотелки / Идеи»
- [x] Плитка/компактный список, просмотр, редактирование и создание карточек
- [x] Изображения, документы, описание, цена, ссылки, заметки
- [x] Коллекции, теги, статусы, приоритеты, избранное, архив, поиск
- [x] Связи между идеями/хотелками, чек-листы идей
- [x] Контекстное меню, массовые действия, системное меню «Поделиться»
- [x] Room, private file storage, FileProvider, без INTERNET permission
- [x] Локальные текстовые черновики редактора
- [x] Корзина с восстановлением, удалением и ручной очисткой
- [x] Ограниченный/проверяемый ZIP импорт + совместимый экспорт
- [x] Явная миграция Room 1→2, транзакционные операции и блокировка гонок
- [x] Тестовые и релизные скрипты, инструкция по подписанию
