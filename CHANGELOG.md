# История изменений

## 1.1.0 — офлайн-версия для релизной проверки · 17 октября 2026

- Корзина: восстановление, окончательное удаление, очистка.
- Миграция Room 1→2 без сброса пользовательской библиотеки.
- Локальные черновики текста в редакторе.
- Редактор закрывается после подтверждения успешного сохранения; защита от двойного нажатия.
- Транзакционные операции и Mutex на изменениях файла/базы.
- Укрепление импорта ZIP: проверка UUID, структуры, лимитов, дубликатов, сохранение старых данных до коммита.
- Экспорт резервной копии включает корзину и проверяет наличие прикреплённых файлов.
- Предел вложений 200 МБ, безопасная очистка частичных копий.
- Исправлена несовместимая конфигурация Android Gradle Plugin и Compose BOM.
- Скрипты структурной проверки, локального smoke-тестирования и подписания APK.
- GitHub Actions: lint, unit tests, debug и unsigned release сборки.
- Инструментальный тест базы, релизный чек-лист, актуальная документация.

**Ограничение:** компиляция, тесты на Android и подписанный APK не выполнены в среде подготовки из-за отсутствующих Android SDK/Gradle dependencies. Исходники не являются подтверждённо проверенной release-сборкой.

## 1.0.0 — исходный прототип
